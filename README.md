# Urban Cart Sales & Profit Dashboard

## Project Overview
The Urban Cart Sales & Profit Dashboard is a Data Analytics project developed to analyze sales performance, profit trends, product categories, and state-wise business performance.

## Tools & Technologies Used
- Microsoft Excel
- MySQL
- Power BI

## Project Workflow
1. Data Cleaning using Excel
2. Data Analysis using MySQL
3. Dashboard Development using Power BI
4. Business Insight Generation

## Dashboard KPIs
- Total Sales: ₹1.02M
- Total Profit: ₹428.26K
- Total Orders: 196
- Top Category: Sports
- Highest Profit State: Gujarat

## Dashboard Features
- Sales by Month Analysis
- Sales by Category Analysis
- Profit by State Analysis
- Gender-wise Sales Distribution
- Top Products Analysis
- Interactive Filters

## Key Learnings
- Data Cleaning
- SQL Query Writing
- Data Visualization
- Dashboard Design
- Business Analytics
